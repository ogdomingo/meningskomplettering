# Meningskomplettering

This code example showcases a sentence-completion exercise for my language learning app. 

## Demo

[![Watch the project demo](https://img.youtube.com/vi/re9BDcz0XZY/0.jpg)](https://www.youtube.com/shorts/re9BDcz0XZY)

## Tools & Technologies

* SwiftUI
* Layout Protocol

## Results and Next Steps

### Overview

I enjoyed the process of learning to use the Layout protocol. It was challenging but worth the effort. I had to think creatively while debugging.

### Debugging

I used randomized background colors for each word in the sentence to check where they might be overlapping, and how much space was allocated automatically.

### Improvements

To improve things, I would add animations between exercises, and perhaps make the dotted line more visible.
